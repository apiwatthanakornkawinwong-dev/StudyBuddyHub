# รวมงาน (เวอร์ชันรายงานความคืบหน้า 50%)

เว็บแอปรวมงานและกำหนดส่งจากหลายรายวิชา เขียนด้วย PHP + MySQL

## วิธีติดตั้ง (XAMPP บน Mac)

1. คัดลอกโฟลเดอร์ `raomngan` ไปไว้ที่ `/Applications/XAMPP/xamppfiles/htdocs/`
2. เปิด XAMPP แล้วกด Start ที่ **Apache** และ **MySQL**
3. เปิด http://localhost/phpmyadmin ไปที่แท็บ **Import** เลือกไฟล์ `database.sql` แล้วกด **Go**
   (ระบบจะสร้างฐานข้อมูลชื่อ `raomngan` พร้อมข้อมูลตัวอย่างให้เอง)
4. เปิด http://localhost/raomngan/login.php

ถ้า MySQL ของเครื่องตั้งรหัสผ่าน root ไว้ ให้แก้ในไฟล์ `db.php` บรรทัด `mysqli_connect`

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| database.sql | สร้างตารางและข้อมูลตัวอย่าง (import ใน phpMyAdmin) |
| db.php | เชื่อมต่อฐานข้อมูล และฟังก์ชันที่ใช้ร่วมกัน |
| header.php / footer.php | เมนูด้านข้าง และส่วนท้ายของทุกหน้า |
| login.php / register.php / logout.php | เข้าสู่ระบบ สมัครสมาชิก ออกจากระบบ |
| index.php | หน้าภาพรวม: แถบภาระงาน 14 วัน งานที่ควรเริ่ม และตาราง 4 ช่อง |
| tasks.php | งานทั้งหมด ติ๊กเสร็จ ลบงาน |
| task_form.php | เพิ่มและแก้ไขงาน |
| calendar.php | ปฏิทินรายเดือน |
| subjects.php | จัดการรายวิชา |
| style.css | หน้าตาเว็บ (ธีมสีครีม) |

## สิ่งที่ทำเสร็จแล้ว (50%)
- สมัครสมาชิกและเข้าสู่ระบบ
- เพิ่ม/ลบรายวิชา พร้อมสีประจำวิชา
- เพิ่ม แก้ไข ลบ และติ๊กงานเสร็จ
- รวมงานทุกวิชาไว้หน้าเดียว กรองตามวิชาและสถานะ
- ปฏิทินรายเดือน
- คำนวณวันที่ควรเริ่มทำตามความยาก (ยาก 5 วัน, ปานกลาง 3 วัน, ง่าย 1 วัน)
- จัดลำดับความสำคัญแบบ Time Management Matrix 4 ช่อง
- แถบภาระงาน 14 วัน บอกวันที่งานส่งชนกัน

## สิ่งที่จะทำต่อ
- ติดตามงานกลุ่มและแบ่งหน้าที่สมาชิก
- ระบบแจ้งเตือน
- แบ่งงานใหญ่เป็นงานย่อย
- สรุปภาระงานประจำสัปดาห์
